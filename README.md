# 时间银行

家庭作业时间存折：默认以20:00为基准，提前完成存入分钟，延时完成在余额内支取，余额不足部分单独注明。

## 发布
仓库 Settings → Pages → Deploy from a branch → main → /(root) → Save。

## iPhone 使用
Safari 打开发布网站，点击“准备离线使用”，完成后添加到主屏幕。从桌面图标重新进入，确认离线资源准备完成，然后开启飞行模式验证记账、关闭再打开后的记录保存。

账目仅存在当前设备的浏览器存储，不上传 GitHub，不自动跨设备同步。Safari与桌面版可能使用不同存储，请固定从桌面图标使用。请定期导出JSON备份，清理网站数据、更换手机或删除桌面应用可能导致丢失。

网页公开，无家长密码保护；家长确认勾选属于家庭约定。使用手机锁屏保护本机账目。离线缓存可能被系统回收，必要时需重新联网准备。
