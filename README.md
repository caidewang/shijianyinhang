# 时间银行

直接选择“存入分钟”或“用掉分钟”，输入正整数，由家长确认。同一天可记录多笔，余额不足时不允许支取。

## 发布与使用
Settings → Pages → main → /(root)。iPhone 用 Safari 打开网站，准备离线使用后添加到主屏幕，并测试飞行模式下记账和重新打开。

账目只存在当前浏览器，不上传 GitHub，不跨设备同步。请定期导出 JSON 备份，勿将真实备份提交到公开仓库。家长确认不是密码保护。

## 旧版迁移
保留原存储键，自动将旧版时间差记录转换为实际存入、支取分钟，保留旧时间与超出额度信息；读取时不覆盖原数据，下一次成功记账才保存新版。支持导入旧版备份。新版备份不能在旧版网页恢复，恢复前请保留原备份。
